# Supermarket: The Night — v0.2.2-alpha

Producer: dixtuel  
Engine: Godot 4.7.2  
Platforms: Windows x86_64, Linux x86_64, and Android 8+.

## Changes

- Rebalanced the complete wave economy: enemy stock-token drops, Harvesting, XP thresholds, shop offer quality, item costs, rerolls, and Endless scaling now use separate wave-aware curves.
- Added Luck and Armor as active player stats. Luck affects offer/drop quality; Armor reduces incoming damage before Protection.
- Added per-enemy HP and damage growth and updated the authored 20-wave roster and Endless pressure scaling.
- Improved enemy steering around shelf and wall obstacles to prevent stale-direction movement and getting stuck.
- Player auto-targeting now skips enemies without a clear firing lane. Projectiles stop on shelves and walls; hitboxes are unchanged.
- Increased the starter can projectile's visual size slightly without changing its collision area.
- Refined dynamic shop and level-up stat presentation and desktop touch-joystick support.

## Downloads

- **Windows x86_64:** `SupermarketTheNight-0.2.2-alpha-Windows-x86_64.zip`
- **Linux x86_64:** `SupermarketTheNight-0.2.2-alpha-Linux-x86_64.zip`
- **Android 8+:** `SupermarketTheNight-0.2.2-alpha.apk` — one signed APK with ARMv7, ARM64, and x86_64 support; install directly without extracting an archive.

This is an alpha build. Balance and crowded-wave performance still need broader device testing.
