# Android and mobile support

This project supports sensor-selected portrait and landscape phones/tablets.
The arena remains a 1920x1080 logical canvas and expands for wider viewports;
menus and overlays must use anchors/containers and respect device safe areas.
The art is pixel-oriented, so mobile rendering stays on the existing GL
Compatibility renderer until device profiling shows a reason to change it.

## Controls and lifecycle

- Gameplay movement uses a dynamic touch stick in the lower-left portion of the
  arena. It only claims its active touch ID, allowing a second finger to use
  buttons on the other side of the screen.
- Touch events emulate mouse input so existing Godot `Button` controls remain
  tappable. Desktop keyboard and gamepad actions remain available.
- Leaving the app clears the active stick, saves the current run snapshot, and
  pauses active gameplay. The lifecycle singleton lowers the frame cap and mutes
  the master bus while suspended, then restores the previous settings.
- Android system Back requests pause/unpause during an arena run. UI screens
  still need to consistently close the topmost modal or return to the prior
  screen; this behavior is assigned to the UI work.

## Android export profile

`export_presets.cfg` includes an Android Gradle APK preset with API 26 minimum,
API 36 target, and ARMv7, ARM64, and x86_64 architectures in one APK. API 26 is
the product's chosen minimum. No signing credentials are committed. Alpha v0.3.1
uses the host's local Godot debug certificate for itch.io sideloading and to
update the connected test installs; future public-store builds need a private
release key.

Godot 4.7's Android guide lists JDK 17, Android SDK Platform 35, Build Tools
35.0.1, Platform Tools 35.0.0 or newer, NDK r28b (28.1.13356709), CMake
3.10.2.4988404, and current Command-line Tools. This host has those packages
plus Android SDK Platform 36 and Build Tools 36.0.0 installed under
`/mnt/Sata SSD/Projects/SDK/android-sdk`, with Temurin JDK 17 at
`/mnt/Sata SSD/Projects/SDK/jdk-17`. Source
`/mnt/Sata SSD/Projects/SDK/env.sh` to configure command-line exports.
Recheck the guide before updating the toolchain because required package
versions can change.

The per-project Gradle template is generated by Godot and ignored by Git.
Install it on a fresh checkout as part of the first export with
`godot --headless --path . --install-android-build-template --export-debug Android builds/android/SupermarketTheNight.apk`.

## Verification status

For alpha v0.3.1 (2026-09-29), the project scan and Linux/Windows release
exports succeeded with Godot 4.7.2. The combined ARMv7, ARM64, and x86_64 APK
passed `apksigner` verification and `zipalign`, installed on the Android 16
(API 36) x86_64 emulator, launched to the title screen, and remained alive
without a crash-buffer entry. The Windows build uses Godot 4.7.2; sustained
Windows 11 touchscreen joystick dragging at 1920×1080 remains unverified, and
the limitation is disclosed in the release notes. A full 20-wave run and
crowded-wave performance remain unverified.
